# Quantum-Deck-v1.0
This is a powerful, tiny and modular and expandable cyber deck in development
## Specs

### Hardware

_Note: this build uses the latte panda mu COM_

-   Intell®️ Processor n100 / Intell®️ Core™️ i3-N305

-   Intell UHD graphics

-   8GB / 16GB LPDDR5 memory at 4800MT/s with in-band ECC

-   64GB eMMC 5.1 storage

-   7" IPS QLED eDP thin bezel screen from waveshare

### Power

The Mu draws 45w of power so I'd recomend a 60w PD charger but if you are using an external graphics card add that to 70 and you should get a good estimate for a charger.

A search term you could use is

> 60 watt power delivery charger
or
> 60 watt laptop charger

### Ports

-    2x 10GB/s USB 3.2
-    1x m.2 slot
-    1x PCIe x1 lane
-    4x USB 2.0
-    1x HDMI
-    2x Display Port
-    1x Ethernet
-    1x 3.5mm audio jack (using a Realtek ALC256)
-    3x Quantumn Deck Expansion Slots
	
### Expanaion ports

Expansion slots are slots for custom made modules that talk over usb 2.0 to better fit seemlesley into the build, for example a USB hub that looks like its integrated but is actually removable.
